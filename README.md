# Placement Tracker

## Overview
***UNPOLISHED ENGINEER****
Placement Tracker is a simple and responsive web application built using **HTML**, **CSS**, and **JavaScript**. It helps users keep track of their placement progress by storing and managing details such as company name, branch, and recruitment status. The application uses the browser's **Local Storage**, allowing the data to persist even after refreshing or reopening the browser.

## Technologies Used

* **HTML5** – Provides the structure and layout of the application.
* **CSS3** – Handles the styling, colors, layout, and responsiveness of the website.
* **JavaScript (ES6)** – Implements the application's functionality, including data storage, editing, deletion, and status management.

## Features

* Add placement details through a user-friendly form.
* Store information such as:
  * Company Name
  * Branch
  * Additional Details
  * Placement Status
* Select placement status using a dropdown menu (e.g., OA Cleared, Assessment Cleared, Interview Selected).
* Edit existing records.
* Delete records when no longer needed.
* Store data permanently in the browser using **Local Storage**.
* Responsive design using **Media Queries** for better viewing on different screen sizes.

## Project Structure

### HTML

The HTML file provides the basic structure of the website. It includes:

* Navigation bar
* Project title
* Placement details form
* Input fields
* Dropdown menu for placement status
* Buttons for different actions

### CSS

The CSS file is responsible for the visual appearance of the application. It includes:

* Layout and alignment
* Colors and typography
* Button styling
* Form styling
* Responsive design using Media Queries

### JavaScript

JavaScript provides all the dynamic functionality of the project, including:

* Adding new placement records
* Editing existing records
* Deleting records
* Updating placement status
* Saving data using **Local Storage**
* Using `JSON.stringify()` to convert JavaScript objects into strings before storing them
* Retrieving stored data and displaying it on the webpage
